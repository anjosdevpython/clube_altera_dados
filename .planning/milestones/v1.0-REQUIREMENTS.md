## v1 Requirements — Final Status

### Robustez & Diagnóstico

- [x] **ROB-01**: Screenshot automático do browser é salvo em AppData quando qualquer passo do Playwright falha — ✅ Entregue v1.0 (tirar_screenshot_erro())
- [x] **ROB-02**: Cada tipo de falha exibe mensagem específica na UI (CPF não encontrado / sessão expirada / timeout / elemento não localizado / login inválido no CRM) — ✅ Entregue v1.0 (classificar_erro())
- [x] **ROB-03**: Falhas de rede e timeout disparam retry automático (até 3 tentativas com backoff de 2s) antes de reportar erro ao operador — ✅ Entregue v1.0 (executar_com_retry())
- [x] **ROB-04**: Seletores do CRM têm fallback (XPath primário + CSS alternativo) para resistir a mudanças no HTML — ✅ Entregue v1.0 (SELECTORS dict + tentar_seletores())

### Log & Auditoria

- [x] **LOG-01**: Toda operação bem-sucedida ou com erro envia POST para endpoint de log centralizado (configurável via `crm_config.json`); falha no POST não bloqueia a operação principal — ✅ Entregue v1.0 (_enviar_log_auditoria() daemon thread)

### UX

- [x] **UX-01**: Log de status mostra progresso por etapa com ícone de check (✓ Logando Zanthus / ✓ Buscando CPF / ✓ Alterando dados / ✓ Confirmado) — ✅ Entregue v1.0 (6 checkmarks em CLUBE_modif.py)
- [x] **UX-02**: Botão "Tentar novamente" aparece na UI após qualquer falha, sem precisar reiniciar o programa — ✅ Entregue v1.0 (mostrar_btn_tentar_novamente())
